# Baixar o Oiê

Pré-lançamento v0.0.1-rc.9

Tenha em mãos uma conta XMPP para começar a conversar.

- [macOS · Apple Silicon](https://github.com/araihu/oie/releases/download/v0.0.1-rc.9/oie_v0.0.1-rc.9_darwin_arm64.tar.gz)
- [Ubuntu 24.04 · x86-64](https://github.com/araihu/oie/releases/download/v0.0.1-rc.9/oie_v0.0.1-rc.9_linux_amd64.tar.gz)

## Instalar com um gerenciador de pacotes

- [APT](../docs/instalacao/index.md#instalar-com-apt) para Trisquel 12 e Ubuntu 24.04 x86-64.
- [Flatpak](../docs/instalacao/index.md#instalar-com-flatpak) para Linux x86-64, com [download do bundle](https://github.com/araihu/oie/releases/download/v0.0.1-rc.9/oie-v0.0.1-rc.9-x86_64.flatpak).
- [Homebrew](../docs/instalacao/index.md#instalar-com-homebrew) para macOS com Apple Silicon e Ubuntu 24.04 x86-64.

O APT e o Homebrew seguem seus próprios canais de atualização.
